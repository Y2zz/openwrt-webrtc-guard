首个公开版本，面向 OpenWrt 24.10.5 / firewall4 / LuCI 24.10，安装包为 `Architecture: all`。

### 功能

- 中文 LuCI 配置页、IPv4/IPv6 规则和受控接口选择。
- 识别任意 UDP 端口上的 STUN 头部特征，补充封禁常用 TCP/UDP TURN 端口。
- 普通与严格两种模式、UDP 白名单、实际规则与命中计数。
- 防火墙重载恢复、配置错误保留旧规则、卸载清理和流量卸载检查。

### 安装

下载本页的 `luci-app-webrtc-guard_0.1.0-1_all.ipk` 与 `SHA256SUMS`，核对校验和，将 IPK 上传到路由器 `/tmp/` 后执行：

```sh
opkg update
opkg install /tmp/luci-app-webrtc-guard_0.1.0-1_all.ipk
```

依赖由与固件版本匹配的软件源安装。首次安装默认关闭；启用前关闭软件和硬件流量卸载，再进入“服务 → WebRTC 防护”。

### 验证与限制

发布流程执行源码检查、可复现打包检查和官方 OpenWrt 24.10.5 用户态容器的真实 IPv4/IPv6 报文测试。测试证据保存在对应 Actions 运行的 `openwrt-test-evidence` 产物中；宿主内核不支持 flowtable 时，该项会明确记录跳过。SDK 安装钩子执行顺序已验证，但本安装包由 Python 工具打包，不是 SDK 编译产物。

尚未在用户实体路由器、其 LuCI 补丁版本或 OpenWrt 原生内核中验证。路由器不能彻底禁用浏览器 WebRTC；TCP/TLS 中继、加密隧道及浏览器本机地址收集不在可靠拦截范围内，不能保证完全防止真实 IP 泄露。
